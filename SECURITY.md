# Security

FlixyPix is a local desktop program. Relevant problems are, for example, a crafted media file,
archive, catalog or backup that makes FlixyPix run code, read or write files outside the places
it should, or reveal an encrypted catalog.

Please report such problems privately through GitHub:
[Report a vulnerability](https://github.com/Kirmalix/flixypix/security/advisories/new).
Do not open a public issue. Include the version, the steps to reproduce and, if possible, a
synthetic file that shows the problem.

Only the latest preview receives fixes. There is no bug bounty.
